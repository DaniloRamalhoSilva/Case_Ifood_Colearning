
# Modelo Preditivo para Otimização de Campanhas de Marketing Direto

Este repositório contém o desenvolvimento de um modelo preditivo com o objetivo de maximizar o lucro em campanhas de marketing direto, focado especialmente na venda de um novo gadget. Com base em uma campanha piloto envolvendo 2.240 clientes, o objetivo da equipe é criar um modelo capaz de prever com precisão quais clientes têm maior propensão à compra.

## Contexto do Projeto

A campanha piloto gerou um prejuízo inicial de **-3,046MU**, com apenas **15%** dos clientes abordados adquirindo o gadget. Com os dados coletados durante esta campanha piloto, incluindo características sociodemográficas e firmográficas dos clientes, além de indicadores sobre suas respostas, este projeto visa reverter esse cenário negativo.

## Objetivos

- Desenvolver um modelo preditivo capaz de identificar clientes com maior probabilidade de adquirir o gadget.
- Maximizar o retorno sobre o investimento das campanhas futuras.
- Oferecer insights detalhados sobre o perfil dos clientes interessados no produto, proporcionando ao CMO informações estratégicas adicionais.

## Dados Utilizados

O conjunto de dados disponível contempla:
- Informações sociodemográficas e firmográficas de aproximadamente 2.240 clientes.
- Indicadores sobre a resposta dos clientes à campanha piloto.

Este projeto pretende demonstrar como uma abordagem analítica avançada pode transformar resultados financeiros negativos em campanhas altamente lucrativas e estratégicas.
